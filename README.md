# game-theory-lab
本项目灵感源于我组织的一次数学主题活动。在活动中，我引入了经典的博弈论模型（如：平分或掠夺 Split/Steal），并设计了一个简单的筹码积累机制。

设计洞察：我观察到参与者在没有任何初始筹码的情况下，通过数轮博弈积累了海量代币 。

核心发现：这种机制包含了极强的成瘾性元素——社交互动、博弈快感以及心理对抗（阴谋/信任）。

项目愿景：我希望将这一线下实验转化为一个面向大众的数字化产品，并利用 AIGC 技术解决内容重复问题，实现“无限局”的动态博弈体验 。



The project was inspired by a mathematics activity I organized, where I implemented a classic game theory model.

Design Insight: I designed a "Split or Steal" gambling mechanism where players, starting with zero tokens, accumulated significant assets through strategic rounds.


Core Discovery: I realized this system taps into core psychological drivers: Social interaction, the thrill of gambling, and strategic conspiracy/trust building.

Vision: My goal was to scale this experiment into a public digital game. By leveraging AIGC, I’ve transformed static puzzles into an infinite stream of dynamic dilemmas, creating a "Game Theory Lab" accessible to everyone.
